# Add your camera photo here

The bottom menu can use your **exact camera photo** instead of the drawn one.

## What to do

1. Save the camera image you want to use as a file named exactly:

   ```
   assets/camera-top.png
   ```

   (A `.jpg` works too — if you use `camera-top.jpg`, tell me and I'll point
   the site at it.)

2. That's it. The site automatically detects the file and swaps the drawn
   camera for your photo. If the file isn't there, it falls back to the
   drawn camera so the site never looks broken.

## How clicking works on the photo

- Clicking the **INSTAGRAM** area opens your Instagram.
- Clicking **anywhere else** on the camera opens the menu.

If a click lands in the wrong spot, tell me and I'll nudge the clickable
zones to line up perfectly with your image (I can fine-tune them once the
real file is in the repo).

## Easiest way to add the file (no tools needed)

On GitHub: open the `assets` folder → **Add file → Upload files** →
drag your image in → name it `camera-top.png` → **Commit**.
