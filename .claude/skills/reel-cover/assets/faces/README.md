# Face library

Drop your expression photos here so you don't have to re-upload them every
time. The `reel-cover` skill picks the file whose expression matches the video.

## Recommended set

Save clean, front-facing, well-lit shots (a plain wall behind you cuts out
best). Suggested filenames the skill knows to look for:

| File | Expression | Matches |
|------|------------|---------|
| `shocked.png` | wide eyes, raised brows, mouth open | big claims, challenges, "I tried…" |
| `serious.png` | calm, straight, confident | business, money, authority |
| `smirk.png` | half-smile | funny, casual |
| `intense.png` | jaw set, locked-in stare | discipline, warnings, drama |
| `thinking.png` | hand on chin | storytime, reflective |

You can add more (`happy.png`, `pointing.png`, etc.). Any front-facing shot on
a plain background works. Higher resolution = cleaner cutout.

Nothing is committed here by default — add your own photos locally, or upload
them in chat each session and the skill will catalog them on the fly.
